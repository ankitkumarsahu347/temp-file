# To-Do List App

A simple responsive To-Do List project built with HTML, CSS and JavaScript.

## Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Save tasks in browser localStorage
- Responsive design

## Run locally

Open `index.html` in a web browser.
